NEXORA ERP Core v0.8

NEW:
1) Bulk piecework rates across multiple selected factory units.
   - Select company, product and one or more units.
   - Enter a common rate to prefill worker rate rows.
   - Edit any worker's rate individually in the spreadsheet-like preview.
   - Save all selected worker rates at once.
2) Sales entry is presented as a multi-line bill/cart.
   - Select a shop and company once for the whole sale.
   - Add multiple product rows to one bill.
   - Quantity, rate and line totals, plus overall bill total are visible.

Start:
1. Extract this ZIP into a folder.
2. Double-click start.bat.
3. Open http://127.0.0.1:8765

Keep your prior database backup. This version can use the v0.7 database; the bulk rate feature updates existing worker/item rates rather than creating duplicate rate rows for the same pair.

This is still a local prototype, not yet a secured production ERP. Do not store confidential data until security, backup, audit, and concurrency protections are implemented and verified.
